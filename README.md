# Fala Comigo

European Portuguese for the whole family: a grown-up course, an Explorer course for older kids, and a picture-and-sound course for little ones.

Open it at **https://owenmatty.github.io/fala-comigo/**

On a tablet, use the browser's *Add to Home Screen* to get an app icon. Progress is saved on each device.

The AI chat partner and listening practice need Claude, so they only work in the claude.ai version of the app. Everything else works here.
